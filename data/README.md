# Course data

`patients.csv` is a **fully synthetic** dataset generated for teaching (seed 20261002). It does not
describe real people.

| Variable | Description |
|---|---|
| `id` | Participant ID |
| `age` | Age in years |
| `sex` | Female / Male |
| `treatment` | Standard / New |
| `sbp` | Systolic blood pressure (mmHg) |
| `bmi` | Body-mass index (kg/m²) |
| `diabetes` | Yes / No |
| `readmitted` | Readmitted within 30 days: Yes / No |
